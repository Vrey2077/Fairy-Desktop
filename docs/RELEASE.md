Fairy Desktop v0.3.1 是首次整理后的公开发布，提供独立 Windows x64 便携版和完整源码。

### 下载
- **win32-x64.zip**：完整解压到可写文件夹，双击“启动 Fairy.cmd”。不需要 Codex 或 Node.js。
- **source.zip**：源码与文档，不含运行数据或 node_modules。
- **SHA256SUMS.txt**：两个压缩包的 SHA-256。

### 功能
- 兼容 Chat Completions 的 API、DeepSeek 预设和直接模型选择。
- 蓝色终端、眼睛状态动画、可跳过的 HDD 风格开屏。
- 会话、草稿、Markdown、停止生成与导出。
- DeepSeek 官方余额、本机每日用量和时段提示。
- Windows 系统语音、自定义音色接口，以及手动关闭/停止。
- 分类设置、字体、间距、快捷键、生成参数和 Fairy 人格。

### 发布与隐私
从独立干净目录构建，明确排除个人 API Key、聊天、草稿、账户信息、导出文件、日志、缓存与备份。公开版使用自绘终端图形，不附带游戏截图、配音或音乐。使用者需自行填写服务商密钥。

### 验证与限制
构建流程执行 20 项协议/存储/语音适配测试与源码隐私扫描。程序目前未签名、无自动更新；系统语音不是游戏原角色配音，外部音色服务需要自行配置。用量为本机统计，时段日历只内置 2026 年节假日。

完整说明、来源和历史版本变化见 README、THIRD-PARTY-NOTICES 与 CHANGELOG。
